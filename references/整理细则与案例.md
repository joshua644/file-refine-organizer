> 本文件是 SKILL.md 的展开。日常整理先读 SKILL.md；遇到命名歧义、查重边界、台账坑时再查本文件。

## 一、命名模板出处对照

模板由两套真实拆分件（同一资金事项的两个批次）的优点融合而成：

| 模板要素 | 来源 |
|---|---|
| 主单带 OA 单号＋金额 | 监理支付01 套 |
| 发票带发票号＋金额 | 监理支付01 套 |
| 合同带合同号＋合同金额 | 监理支付01 套 |
| 发票分专票/普票 | 采购报销套 |
| 审批表不带冗余后缀 | 采购报销套 |
| 入账单带联次、验收报告带数量、补充协议带变更要点 | 采购报销套 |

**原文件处理规则（2026-10-17 傍晚最终定）**：合订 PDF 拆分后**只留拆分件**；原件移入暂存区，用户确认后清空。废止了上午「原件保留不动」的约定。文件资料台账按原名登记的行，同步改为指向拆分文件夹或暂存说明。

## 二、合订 PDF 四步拆分法细节

### 1. 摸结构（inspect_pdf.py）

逐页输出：文本字符数、图片数、页面尺寸（横/竖）。规律：
- 文本量>200 字符 → 电子文档（主单、发票、系统打印件），直读文本；
- 文本量≈0 → 扫描件，必须渲染目视；
- 横向页多为电子发票。

### 2. 渲染目视判界

100 DPI 足够辨认文字。每块扫描件看三类页：**首页**（标题/文号）、**疑似结尾页**（落款/盖章）、**中间抽查页**（防块内有独立文档）。水印页码（如「17/31」）是装订顺序的可靠佐证。

### 3. 拆分与边界经验

- `insert_pdf` + `garbage=3, deflate=True`。
- **合同包不拆**：封面+协议书+通用条件+专用条件+成交通知书+采购需求书，看合同「组成合同的文件」条款——列为一套的保持一个整件。
- **宁少切不拦腰断**：一页跨两份文档的（罕见但存在），宁可少拆一件，不可把一份文档拆成两半。
- **同夹多件加日期前缀**：一个合订包含两笔不同日期事项时，文件夹名取主事项日期，附件名带各自日期防混淆。
- **小额支付资料三页算一包**：主单+发票+审批表三页的，不强行找「文档边界」，整包归一个事项文件夹。
- **施工类比监理类多两张监理签认表**：工程款支付证书＋工程款支付报审表——施工请款资料通常比监理多 1-2 件附件。
- 纯扫描无主单的包，从附件1 起编。

### 4. 双项校验

```
各件页数之和 == 原总页数
逐件首页文本/渲染图与身份吻合
```

## 三、查重三轨判据表

| 轨 | 工具 | 抓什么 | 抓不到什么 |
|---|---|---|---|
| MD5 | md5sum/hashlib | 一字节全同的重复 | 同内容不同导出（水印页码不同、重新打印） |
| 同文件名/同大小 | find+比对 | 同文档两次生成 | 改名后的重复 |
| 内容级目视 | 渲染 PNG 比对 | 跨批次同内容、名实不符 | —— |

**跨批次共用材料保留原则**：合同/审批表/成交信息在两笔独立请款批次中各装一份，属正常归档形态，删任何一边都会让该批次报账附件不完整——**保留**。
**散件 vs 拆分件**：系统单独导出的发票与合订包拆出的同票号发票，留拆分件、删散件。
**名实不符**：文件名与内容不符时（如「请款函」实为合订包、「付款申请」实为单张发票），按内容重新归类，并在台账注明原名。

## 四、结构统一规则

- 资金资料固定三层：`<项目>/06-资金台账/01-发票与请款资料/<事项文件夹>/`，不留多余中间层（如 `04-付款申请` 这类二级套层要扁平化）。
- 二级目录编号唯一且顺延（01/02/03……），出现重号时顺延后者。
- 目录名与内容不符时，先看内容再改名——同名子目录同时出现在两个一级目录下时（如「02-采购文件」在 03-招标采购 和 04-合同 下都有），逐个看内容判断哪个错位，不凭目录名猜。
- 有意存档不动：`99-重复备份`（带「与…逐页同文」对照说明）、`_备份_<日期>`、根目录大事纪要与 mpp 进度文件（惯例放法）。

## 五、台账同步坑（文件资料台账 jsonl）

1. **「文件名」字段格式不统一**：多数行是纯文件名，个别行带完整相对路径前缀。批量匹配用 `endswith(key) or key in fn` 双条件，改后逐行回验命中数。
2. **改前必备份**：`.bak-<日期>`，同日多次操作用 `-2`、`-3` 顺延。
3. **状态字段写清楚去向**：如「2026-10-17 原件移出至 AI工作产物/…/去重暂存_20261017/合订原件_20261017（只留拆分件）」。
4. **拆分件是否补登台账**：默认不补登（延续先例），若要求全覆盖须逐件登记；资金数据口径以线上合同／支付台账系统为权威源的，本地不建资金台账表。

## 六、磁盘名不可见字符坑

文件夹真实名可能带不可见字符（实测遇到反引号 U+0060 混入）。按显示名 `mv` 后会出现「新旧双份」。处置：MD5 逐一比对确认内容相同 → 残留移暂存区。**改名前先用 `ls | cat -A` 验字节**。
